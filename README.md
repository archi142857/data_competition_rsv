# 일본 RSV 유행의 지역별 관계와 4주 후 보고 수 예측

제1회 과학데이터혁신 경진대회(서울대 과학데이터혁신연구소)에 참가하면서 일본 RSV 전파 데이터를 분석한 코드다.

한 현의 RSV 보고 수를 4주 앞서 예측할 때, 가까운 현 세 곳의 최근 보고 수를 같이 넣으면 예측이 나아지는지 확인했다. 일본 전체가 같은 계절 주기를 따라서 생긴 효과일 수도 있어서 전국 합계를 넣은 모델과도 비교했다. 마지막에는 평가 연도를 2015~2023년으로 넓혀서, 유행 시기가 바뀐 해에도 인근 정보가 쓸모 있는지를 과거에서 배운 계절 패턴과 견주어 봤다.

## 결과

중간보고서까지 (고정 설계, 스크립트 01~06)

- 인근 3현 정보를 넣으면 2021년, 2022년, 2023년 모두 로그 MAE가 줄었다. 세 해를 합치면 0.818에서 0.739가 됐다.
- 전국 합계를 이미 넣은 모델에 인근 정보를 더해도 2021년과 2023년에는 오차가 더 줄었다.
- 2022년에는 오사카, 아이치, 효고에서 7월 정점 직후 예측이 실제보다 크게 나와서 원래 단위의 RMSE가 81.0에서 93.6으로 커졌다.

최종보고서에서 더한 것 (스크립트 07~13)

- 2022년 세 현의 과대 예측은 인근 정보를 넣기 전부터 있었고, 인근 3현의 4주 변화 입력이 이를 더 키웠다. 인근 현이 먼저 정점에 이른 현에서는 인근 정보가 정점 전후의 오차를 줄였고, 자기 현이 먼저 정점에 이른 현에서는 키웠다(사후 진단).
- 인근 3현을 무작위 3현으로 바꾸면 전국 합계 모델에 더했을 때의 개선이 0.025에서 0.003으로 줄었다. 이득은 가까운 현일수록 컸다.
- 세 해 전체의 결론은 인근 현의 수나 고르는 방식을 바꿔도, 보고가 2주 늦어도, 그래디언트 부스팅으로 바꿔도, 오키나와나 2020년 자료를 빼도 같았다.
- 기준으로 삼은 M1은 현재값을 그대로 쓰는 M0와 비슷한 정도로 약했다. 계절 입력을 빼서 기준을 강화하면 인근 정보의 이득(M2와 M1의 로그 MAE 차이)은 0.079에서 0.049로 줄었고, 최근 26주 평균 입력을 넣었을 때는 0.059, 부스팅에서는 0.057이었다. 줄어도 신뢰구간은 0보다 아래였다.
- 2022년의 개선은 작았고, 주 단위로 묶어 다시 뽑은 구간은 0을 포함한다.
- 유행의 무게중심 예측은 0.6주쯤 나아졌다. 유행 시작 주의 오차는 어느 모델이나 4주 안팎이었고, 인근 정보가 시작 주 예측을 개선했다는 근거는 얻지 못했다.
- 그래디언트 부스팅의 수치는 입력 끝자리의 작은 차이에도 소수 셋째 자리가 달라졌다. 보고서에는 잡음을 더한 10번 반복에서 방향이 바뀌지 않은 결과만 적었다.
- SIRS 가상 자료 실험은 가정(외부 유입, 전파율 감소 폭)에 따라 결과가 바뀌어서 보고서 본문의 근거로 쓰지 않고 부록 B에 적었다.
- 기준을 더 강하게 잡으면(자기 현 이력 8~12주, 전국 입력에 인근 입력과 같은 형태의 값 추가, 계절 입력 제외) M2와 M1의 차이는 릿지 -0.023~-0.046, 부스팅 -0.025~-0.043으로 줄었지만 구간은 0 아래였다. 전국 입력을 넣은 뒤의 차이(M4 − M3)는 릿지에서 -0.012로 남았고, 부스팅에서는 -0.001~-0.010이었으며 가장 강한 기준에서는 0과 구분되지 않았다. 무작위 3현(릿지 30번)은 어느 기준에서도 인근 3현보다 낫지 않았다.
- 강한 기준의 연도별 값은 회귀 모델에 따라 갈렸다. 계절 입력을 뺀 두 기준에서 2021년의 M2와 M1의 차이는 릿지 0.002~0.003으로 0과 구분되지 않았고 부스팅에서는 -0.031~-0.035로 남았다. 릿지의 기준 B를 2015~2019년에 적용하면 다섯 해 모두 음수였지만 2015~2017년은 구간이 0을 포함했다(2020년을 뺀 여덟 해 묶음 -0.015 [-0.021, -0.009]).
- 인근 현의 수, 릿지 α, 계절 입력 여부를 평가 연도 이전의 자료(2015년부터)만으로 고르면 세 해 모두 계절 입력을 빼는 쪽이 골라졌다. 그렇게 고른 M2와 M1의 차이는 -0.053 [-0.066, -0.040](주 묶음 [-0.086, -0.019])이었고, M4와 M3의 차이는 -0.004 [-0.017, 0.010]로 0과 구분되지 않았다. 이때 M4에는 24현과 12현이 골라졌는데, 검증에서 2020년을 빼면 M4도 8현이 골라지고 차이는 -0.019 [-0.030, -0.007](주 묶음 [-0.045, 0.006])이었다.
- 2022년의 개선은 예측 시점의 보고 수가 적은 행에 몰려 있었다(5건 미만 -0.046, 5건 이상 -0.007, 차이 -0.039 [-0.073, -0.007], 주 묶음으로는 [-0.123, 0.016]). 세 해 전체로는 0건, 1~4건, 5~19건, 20건 이상 구간 모두에서 M2가 나았다. 세 해 전체로 M2가 M1보다 나은 현은 47개 가운데 45개, M4가 M3보다 나은 현은 36개였다.

평가 연도를 2015~2023년으로 넓힌 것 (스크립트 14, 보고서 6.8절)

- 계절 입력(목표 주의 sin, cos)의 효과는 해마다 부호가 바뀌었고, 그해 전국 곡선이 과거와 닮을수록 도움이 되는 경향이 있었다. 릿지에서 2015년에는 로그 MAE를 0.084 줄였고 2021년에는 0.155 키웠다. 닮음과 계절 입력 효과의 순위 상관은 릿지 -0.82, 부스팅 -0.90이었다. 다만 해마다의 방향이 두 회귀 모델에서 뚜렷하게 일치한 해는 2015년(도움)과 2020년, 2021년(해)이다.
- 릿지에서 2018~2019년에 계절 입력이 해가 된 것은 sin, cos 한 쌍이라는 형태의 영향이 컸다. 주 번호마다 항을 따로 두면 2018년의 손해는 사라지고 2019년에는 도움이 됐다. 2021년과 2023년의 손해와 순위 상관(-0.88)은 그대로였다.
- 인근 3현의 효과는 보고가 급감한 2020년을 뺀 여덟 해 모두 오차를 줄이는 쪽이었다. 자기 현의 최근 값만 쓰는 모델에 인근 3현을 더하면 로그 MAE가 릿지에서 0.016~0.086, 부스팅에서 0.021~0.073 줄었다. 2017년은 0과 구분되지 않았다.
- 여덟 해를 묶은 효과(릿지 -0.041)의 절반은 무작위 3현으로도 얻었다(-0.021). 가까운 현이어야 얻는 몫은 2015~2019년 0.015, 2021~2023년 0.030이었다.
- 계절 입력이 맞은 해(2015, 2016, 2022년)에는 M2와 M1의 차이가 0.011~0.022로 작았고, 맞지 않은 해에는 0.036~0.123으로 컸다. 고정 설계에서 본 이득의 일부는 어긋난 계절 패턴의 손해를 인근 정보가 메운 몫이었다.
- 전국 합계를 넣은 모델에 인근을 더했을 때의 차이는 2015~2019년 -0.007에서 2021~2023년 -0.025로 커졌다(2021년과 2023년에 컸고 2022년은 -0.003).
- 이 분석은 5장과 6.7절의 결과를 본 뒤에 더한 것이고 해가 아홉뿐이다. 계절 입력은 모든 현에 같은 값이라 현 단위 신뢰구간이 좁게 나온다. 주 묶음으로 다시 뽑은 구간을 함께 저장했다.

이 결과는 인근 현의 보고가 예측에 쓸모 있다는 것까지다. 현 사이의 전파 경로를 밝힌 것은 아니다.

**1. 자료 넣기**

```
data_competition_rsv/
├── RSV_transmission_in_Japan/
│   ├── cases.csv
│   └── ...
├── code/
└── ...
```

**2. 패키지 설치**

```
pip install -r requirements.txt
```

Python 3.13, numpy 2.5.3, pandas 3.0.5, scikit-learn 1.9.1, scipy 1.18.1, matplotlib 3.11.2에서 돌려 봤다. 릿지 회귀의 결과는 환경이 달라도 같게 나오지만, 그래디언트 부스팅(`10`)은 버전이나 계산 순서가 달라지면 소수 셋째 자리가 달라질 수 있다.

**3. 실행**

노트북은 `RSV_final_analysis.ipynb`를 열고 위에서부터 실행하면 된다. 전체가 15분쯤 걸린다.

스크립트는 저장소 폴더에서 아래처럼 돌린다. 파일마다 필요한 계산을 처음부터 다시 하기 때문에 순서와 상관없이 하나만 돌려도 된다.

```
python code/01_data_check.py
python code/04_forecast_eval.py
python code/08_neighbor_def.py
```

대부분 몇 초면 끝난다. 오래 걸리는 것은 `07`(20초), `08`(무작위 200번, 1분), `10`(잡음 확인 10번 포함, 1분 20초), `12`(부스팅 포함, 1분 반), `13`(모의실험 200번, 4분), `14`(부스팅 6번과 무작위 50번, 5분)이다.

그림은 `figures/`에, 표는 `results/`에 저장된다. `results/facts_*.csv`는 보고서 본문에 쓰는 낱개 숫자를 모아 둔 파일이다.

## 분석 설정

- 예측 대상: 각 현의 4주 뒤 주간 보고 수
- 평가: 2021년, 2022년, 2023년을 한 해씩 따로 평가. 학습에는 평가 연도 1주 전까지 결과가 확인된 자료만 씀
- 모델: M0 현재값 유지, M1 자기 현 이력, M2 인근 3현 추가, M3 전국 추가, M4 인근과 전국 추가 (M1~M4는 릿지 회귀)
- 인근 현: 현 대표 좌표 사이 거리가 가장 가까운 세 현
- 지표: 로그 MAE(주 지표), 원래 단위 MAE와 RMSE, 규모 보정 MAE. 신뢰구간은 현 단위 부트스트랩 2,000회
- 외부 자료는 쓰지 않았다(대회 규정). 문헌은 배경과 해석에만 인용했다

추가 분석에서 임의로 정한 값

- 그래디언트 부스팅: 학습률 0.05, 300회 반복, 조기 종료 없음. 주제를 정할 때 시험 삼아 쓰던 값 그대로이고 결과를 보고 바꾸지 않았다
- 유행 시작 주: 5~52주 실제 최댓값의 25% 이상인 주가 2주 이어지는 첫 주 (10%, 50%로도 확인)
- 주 묶음 부트스트랩: 예측 시점을 8주씩 묶어서 다시 뽑음 (현 단위 구간과 비교용)
- 코로나 유행기: 전국 합계가 2013~2019년 최솟값보다 낮았던 2020년 17~40주. 2020년 10주(전국 휴교 요청 직후)부터 그해 말까지, 2021년 26주까지로 넓힌 것도 확인
- 기준 모델 강화: 계절 입력(sin, cos)을 네 모델에서 제외. 이때의 무작위 3현 대조는 50번
- 부스팅 계산 잡음: 인근 입력에 1e-12 크기의 정규 잡음을 더해 10번 반복
- 평가 연도 넓히기: 2015~2023년. 2014년은 학습에 쓸 자료가 2013년 한 해뿐이라 뺌. 여러 해를 묶을 때는 보고가 급감한 2020년을 뺌
- 과거와의 닮음: 그해 전국 합계(log1p)의 1~52주 곡선과 그 전 모든 해의 평균 곡선의 상관. 직전 3년, 직전 해, 과거에서 2020년 제외로도 확인
- 직전 3년 학습: 목표 연도가 평가 연도보다 1~3년 앞선 행만으로 릿지를 다시 학습
- 더 강한 기준(6.7절): 자기 현 이력 8주 = 지연 4~7주, 최근 8주 최고치와 견준 수준, 최근 26주 평균. 이력 12주 = 거기에 지연 8~12주, 1·2·8주 변화, 4·8·13주 이동평균. 전국 입력 확장 = 자기 현을 뺀 46개 현의 로그 평균, 그 4주 변화, 자기 현과의 차이. 더 확장 = 거기에 전국 합계의 지연 1~3주, 1·2주 변화. 무작위 3현 대조는 릿지 30번
- 과거 자료만으로 설정 고르기(6.7절)의 후보: 인근 현 수 1, 2, 3, 5, 8, 12, 16, 24, α 0.01, 0.1, 1, 10, 100, 계절 입력 넣음과 뺌. 검증에 쓴 해는 2015년부터 평가 연도 전 해까지(2020년을 뺀 것도 함께 계산)
- 주 묶음 부트스트랩의 묶음 길이: 기본 8주, 4·13·26주로도 확인. 예측 시점 보고 수 구간: 0건, 1~4건, 5~19건, 20건 이상
- 계절 입력의 표현 바꾸기: 조화 항 둘(sin, cos 두 쌍), 주 번호마다 항 하나(53주째는 52주 항에 붙임). 릿지로만 확인
- 평가 연도 넓히기의 무작위 3현 대조: 릿지 50번
- 평가 연도 넓히기의 부스팅 계산 잡음: 계절 입력을 뺀 입력에 1e-12 크기의 정규 잡음을 더해 5번 반복
- 모의실험: 감염 기간 1주, 면역 평균 52주, R0 3, 계절 진폭 25%, 2020년 10주부터 1년간 전파율 50%(30%, 70%도 확인), 현 사이 연결 비중 0.5%, 외부 유입 1e-8. 자료에 맞춘 값이 아니고, 연결 비중과 외부 유입은 몇 번 돌려 본 뒤에 잡았다
